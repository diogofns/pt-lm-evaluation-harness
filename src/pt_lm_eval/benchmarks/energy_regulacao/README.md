# energy_regulacao

Questões de múltipla escolha (5 alternativas) sobre a regulação do setor elétrico
brasileiro. Cada questão vem acompanhada do trecho normativo de onde foi tirada
(coluna `right_context`, não usada nos prompts).

## Fonte

- Dataset: [`cemig-ceia/energy-eval`](https://huggingface.co/datasets/cemig-ceia/energy-eval), split `train`
- Revisão fixada: `cac76ae9456fc3c9354d761880bc3c3a5b54d1e1`
- 500 itens, nenhum descartado.
